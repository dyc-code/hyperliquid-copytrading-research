# 前瞻研究协议（待执行）

## 目标

在新的时间段检验两个问题：固定的稳健选人规则能否优于过去收益榜；在相同实际可分配资本和风险约束下，跟随者能否获得正的成本后净收益。当前历史研究无法回答第二个问题。

## 事前固定

- 开始采集前确认账户范围、金额单位、时区和字段字典，并保存数据版本及参数哈希。
- 预先确定非重叠观察窗口、两组共同准入条件、名单和权重生成规则。每个窗口只使用决策时刻已到达的数据。
- 两组采用相同资本预算、风险限制、盘口可得性、执行延迟和费用计算口径。完整窗口、资料不足窗口以及名单或权重相同的窗口都进入全期记录；方法区分能力单独报告。
- 缺失的来源事件、持仓、盘口、订单终态或我方对账不得按零收益处理，也不得事后替换入选地址。

## 必须采集

来源完整持仓及权益、净入金事件、来源事件时间、我方接收与决策时间、对应盘口深度、拟单、实际订单与成交回报、手续费、资金费、滑点、撤单终态和持续的现金加持仓账本。

## 执行顺序

先运行真实资金为零的影子系统，记录自然发生的交易生命周期，核对目标仓位、可下单性与成本。随后在共同准入池内进行配对对照。任何真实资金试验都需要额外的逐来源数据质量、容量与技术准入；本协议没有给出启资批准。

## 判定

报告全部预定窗口、覆盖率、净收益、回撤、最差日、成本、遗漏与拒单。若证据仍不支持原假设，保留负面结果并停止该版本；新参数须另建协议与样本，不覆盖既有结果。成本情景中的费率、滑点和延迟只是待检验假设，不能预先视为真实成交结果。
