# Hyperliquid 多交易员跟随策略：可复制性研究

一项独立量化研究，检验能否从账户日快照中识别值得跟随的交易员，以及历史账户收益能否代表跟随者可获得的净收益。

**核心发现：** 固定筛选规则在八个未来观察窗口中只有三个窗口与收益榜同时具备完整数据；三个同窗比较均落后，平均每轮低 **3.97 个百分点**。这不能证明收益榜长期更好，也不能将任何账户收益解释为可成交的跟随收益。

## 数据来源和复现

研究使用外部提供的地址级账户日快照，区间为 2025-07-10 至 2026-01-04，含 2,000 个地址、179,355 行。数据提供方未说明地址抽样、字段字典及采集过程。**本仓库不分发原始 CSV 或地址级明细，也不能仅靠公开文件从零重算历史结果。** 公开的是方法代码、原始文件的 SHA-256、聚合输出及图表。[数据说明与复现步骤](docs/data_and_reproducibility.md)列明所需字段与运行方法。

本项目没有真实跟单、实际资金投入或同行评审发表。历史策略结果是不含成交成本的账户收益代理实验；可交易性尚待新数据与影子系统检验。
